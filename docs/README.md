# Documentation

This directory contains Beaver Nest's general repository documentation that is not a canonical repository rule. Its organization follows the [Diátaxis framework](https://diataxis.fr/); the canonical repository convention is [documentation architecture](../repo-governance/conventions/documentation-architecture.md).

Repository rules and working agreements remain in [repository governance](../repo-governance/README.md).

## Directory Map

- [Tutorials](tutorials/README.md) provide learning-oriented lessons.
- [How-to guides](how-to-guides/README.md) provide goal-oriented directions.
- [Reference](reference/README.md) provides precise technical information.
- [Explanation](explanation/README.md) provides context and understanding.
