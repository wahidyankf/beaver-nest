# Quality Standards

This directory holds the language-neutral quality standards and stack packs adopted from the shared software-development
catalog. Existing local standards one level up, such as [Quality Gates](../quality-gates.md), keep their authority; each
adopted document here links to them wherever they own a concept.

## Directory Map

- [Code](code/README.md) holds the adopted type-safety and shell-script standards.
- [Stacks](stacks/README.md) holds the adopted stack standards and this repository's adapter.
- [Testing](testing/README.md) holds the adopted coverage standard.
