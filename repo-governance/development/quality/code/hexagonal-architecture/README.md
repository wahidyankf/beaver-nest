# Hexagonal Architecture Modules

Read in order. Together these hold the rule the [Hexagonal Architecture](../hexagonal-architecture.md) entrypoint
indexes.

## Directory Map

- [001 Domain-Driven Design](001-domain-driven-design.md) defines bounded contexts, their language, their published
  interfaces, and the tactical patterns adopted.
- [002 Layers and the Dependency Rule](002-layers-and-the-dependency-rule.md) defines each layer's contract, the
  composition root, and Functional Core, Imperative Shell.
- [003 Application Shapes](003-application-shapes.md) defines which layers a context needs and the order code is
  written in.
- [004 Test Doubles](004-test-doubles.md) defines in-memory adapters, contract suites, and which layer proves what.
