# PR Leak Review Modules

Read in order. Together these hold the rules the [PR Leak Review](../pr-leak-review.md) entrypoint's steps apply: what a leak is, the private review of each push, and the mechanical enforcement of both.

## Directory Map

- [001 Leak Classes](001-leak-classes.md) defines the three classes, what is not a leak, and why history is the subject.
- [002 Push Review](002-push-review.md) reviews each outgoing range privately and fixes remediation before and after a push.
- [003 Enforcement](003-enforcement.md) holds the range screen, the hosted checks, the required status, and this repository's decisions.
