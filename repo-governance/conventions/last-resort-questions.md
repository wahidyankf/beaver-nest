# Last-Resort Questions

Ask the user for information, clarification, confirmation, or a decision only after exhausting safe, reasonable, and in-scope ways to proceed independently.

## Before Asking

- Inspect applicable instructions, governance, repository files, history, configuration, current state, and available tool output.
- Run relevant read-only diagnostics and use existing repository evidence to resolve uncertainty.
- Make a reasonable, clearly bounded assumption when it is reversible, low risk, and unlikely to diverge from the user's intent.
- Try viable in-scope alternatives and continue all independent work that does not depend on the missing answer.
- Do not ask the user to repeat information already provided or discoverable from the repository or environment.

## When Asking Is Necessary

Ask only when progress requires information or authority unavailable elsewhere and proceeding by assumption would materially risk incorrect work, harm, irreversible or external side effects, rule violations, or a meaningfully different outcome.

Ask the minimum number of concise questions needed. State the blocker, what was already checked or attempted, and why no safe default remains.

This convention does not waive explicit authorization requirements or permit unauthorized action. When a rule reserves a decision for the user, obtain it after completing every independent prerequisite and check. Do not create extra work merely to avoid a genuinely necessary question.
