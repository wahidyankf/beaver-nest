# Learnings

## Capture Rule

Record only safe facts: source revision, target name, port role, pass/fail, duration, aggregate process resource values, and anonymous synthetic-journey outcome. Do not record machine paths, hostnames, Tailscale identity, credentials, cookies, keys, user names, user records, request payloads, or logs containing them.
