## Capture Rule

Record only repository-relative paths, public tool versions, official documentation conclusions, aggregate counts, commands, pass/fail, and non-sensitive diagnostics. Never record credentials, provider account data, machine paths, hostnames, session content, model prompts/responses, user-global configuration, or private MCP output.
