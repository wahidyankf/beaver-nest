# UI Assets

These plan-owned synthetic SVGs let product reviewers and implementers compare three responsive Admin settings schedule concepts. They show contextual groups, settings navigation, and expiry summaries without production paths, users, records, or backup data.

## Alternatives

- `ui-ledger-lofi-*.svg`: selected comparison ledger.
- `ui-timeline-lofi-*.svg`: rejected seven-day timeline.
- `ui-cards-lofi-*.svg`: rejected independent status cards.
- `ui-ledger-hifi-*.svg`: selected Nest workshop treatment.

Each family includes desktop, tablet, and mobile widths. Source copy and behavior are canonical in [technical design](../tech-docs.md).
