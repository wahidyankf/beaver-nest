# Delivery

Every command runs through the pinned HIPPO guard. `HIPPO` below abbreviates `./hippo run --class ephemeral --disk-path . --`; write it in full when executing. Upstream work happens in the local RHINO checkout, referred to below as `<rhino-checkout>`; consumer work happens in this repository. Commit and push in either repository require separate [authorization](../../../repo-governance/conventions/commit-authorization.md).
